# mass-system

Symbolic solve of the 5x5 linear system relating the accelerations of a coupled two-mass
arrangement, to obtain the equivalent mass `Meq` seen at the tool.

**Tool:** Octave with `pkg load symbolic`.

```bash
octave mass_system.m
```
