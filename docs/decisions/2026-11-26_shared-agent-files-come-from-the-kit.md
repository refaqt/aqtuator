# The agent entry files come from the shared kit

- **Date:** 2026-11-26
- **Status:** Accepted

## Context

Agents in this repository read about 82 KB of instructions before they started any work. Most of
it was the full set of 22 mistake notes, the coding patterns, and rules that only matter for one
kind of task. `CLAUDE.md`, `AGENTS.md` and the Cursor rules had also drifted away from the
templates in the shared kit.

## Decision

- `CLAUDE.md`, `AGENTS.md`, `.cursor/rules/refaqt-*.mdc` and the pull request template are
  generated by the kit's `sync_root.py`, from `.agents-local/profile.toml`. Nobody edits them by
  hand.
- What is true only for this repository lives in `.agents-local/rules/repo.md`, under 3 KB. The
  generic parts of the old file moved to the kit: GitHub Actions rules and "pass or fail needs the
  data sheet" are now kit skills.
- Agents read the mistakes index at the start of a task, not every note. A script writes the
  table in `docs/mistakes/README.md`.
- The coding patterns load only when the task needs them, as the skill `patterns`.
- CI checks that the generated files match the kit and that start-up text stays under 24 KB.

The full reasoning is in the kit:
[refaqt-agents decision record](https://github.com/refaqt/refaqt-agents/blob/main/docs/decisions/2026-11-26_lean-agent-context.md).

## Consequences

- Start-up text falls from about 82 KB to about 20 KB.
- To change a shared rule, change the kit. A weekly job opens a pull request here when the kit
  changes.
- The old Cursor rule files are gone. Cursor reads `AGENTS.md` and the generated rule files.
