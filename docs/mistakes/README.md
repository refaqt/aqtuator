# Mistakes

Incidents worth not repeating. One file per incident: `YYYY-MM-DD_topic.md`, with a
`## Prevention rule` section. Read this index at the start of a task, not every note. Open a note
only when its rule matches your task.

Three kinds of mistake came back more than once:

- Bash syntax used in PowerShell (four times). The rule is in `.agents-local/rules/repo.md`.
- A number or a conclusion given before the source was opened (three times). Use the skill
  `source-documents`.
- The shared tooling going wrong without a word (twice). Run the first step in `CLAUDE.md`
  yourself, and never put the tooling folders back to an older version.

`python3 .agents/scripts/mistakes_index.py`.
