# 2026-11-26 — HIWIN E2 lubrication units leak when mounted vertically

**Role(s):** engineering, purchasing

## What happened

The HIWIN E2 lubrication units cannot be used in a vertical position. In that position they
start to leak. The E2 unit is the oil unit that fits on the end of the guide block. Our guide
blocks are the QEH15SA type with the E2 unit. In a vertical setup, grease is the better choice.

## Decisions

- Do not use the E2 oil unit on any guide that runs vertically.
- For vertical setups, plan with grease instead. This stays open until HIWIN or Vansichen BV
  answer the questions below.

## Open Questions

Ask Vansichen BV or HIWIN these questions:

1. How do we grease the guide blocks in a vertical setup? Which grease, how much, and by which
   grease nipple or port?
2. How often must we grease them in a vertical setup?
3. How can we reduce maintenance? For example: a longer grease interval, a different seal, or
   an automatic grease supply.
4. Which oil does the E2 unit hold, and what is the fitting limit for tilted positions? This is
   still open from the
   [answer of 2026-11-10](2026-11-10_hiwin-answers-e1-drive-and-guides.md).

## Next Steps

- Send the questions to Vansichen BV. They already handle our HIWIN quote. Copy HIWIN GmbH if
  Vansichen BV cannot answer.
- Check which guides in our designs run vertically. Then decide if they need grease blocks.
