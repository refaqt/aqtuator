# 2026-11-24 — The compact stage will use the 230 mm RSF tape

**Role(s):** architecture, purchasing

## Goal

Decide how long the measuring length of the RSF MC 15 MK tape must be. The 240 mm tape covered the
full travel, also with both dampers fully pressed. Niels Bosmans asked whether that is needed, and
proposed the 220 mm tape.

## Short answer

- **The crash zone does not need to be measured.** When the dampers are pressed in, the motor must
  stop anyway. If the head loses the tape there, the drive stops the motor. That is the safe
  reaction. The crash study also shows that the read head gets the least shock when the motor
  stops at the crash.
- **The 220 mm tape is too short.** The carriage moves 222 mm between the first touches of the two
  dampers. With 220 mm, the head is already 1 mm past the tape at each damper touch. The software
  limits would then have to keep the working travel at about 218 mm. A carriage that rests against
  a damper would have no position at start-up, so someone would have to push it back by hand
  before the linear motor can start.
- **We chose the 230 mm tape** (MB-MC15-MK-ML230, tape 250 mm long). At each damper touch the head
  stays 4.0 mm inside the measuring length. With the dampers fully pressed, it runs 3.0 mm past
  each end. Niels Bosmans chose this option.
- **The CAD now holds the 230 mm tape.** The base and the assembly were changed in the FreeCAD
  window later the same day. The head reads the tape with the same 0.55 mm gap, and no part
  touches the tape.

## Work Done

- **Parts library:** the stoq library has a new part, the 230 mm tape. The stage points at the
  stoq version that holds it.
- **Bill of materials and architecture:** the tape row and the tape description name the 230 mm
  tape. The measuring length in the read interface is 230 mm. The start of the tape on the base
  is written as x = 356 mm.
- **CAD:** in the base, the start of the tape moved from x = 361 to 356 mm. In the assembly, the
  230 mm tape replaces the 240 mm tape, on the same mounting frame. No other part moved.

| Position of the carriage | Sensor x | Inside the measuring length, start end | Inside the measuring length, base end |
| --- | ---: | ---: | ---: |
| Damper touch, base end | 120.800 mm | 226.0 mm | 4.0 mm |
| Damper touch, start end | 342.800 mm | 4.0 mm | 226.0 mm |
| Dampers fully pressed, base end | 113.800 mm | 233.0 mm | **−3.0 mm** (past the end) |
| Dampers fully pressed, start end | 349.800 mm | **−3.0 mm** (past the end) | 233.0 mm |

## Decisions Made

- The measuring length covers the travel up to the first damper touch, not the crash zone. A lost
  position in the crash zone is treated like any other encoder error: the drive switches the motor
  off.
- 230 mm, not 220 mm: the 4 mm margin at each end lets the carriage rest on a damper and still
  start, and it leaves room for the mounting tolerance of the tape.
- The interface versions stay the same. Only the length of the tape and its start position change.

## Next Steps

1. Ask RSF to confirm that ML 230 mm can be ordered. Then order the tape as MC 15 MK with ML 230 mm.
2. Set the software limits of the drive inside the 230 mm measuring length.
