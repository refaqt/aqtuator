# 2025-06-27 — High-Z axis Z-plate modification

- Modification of the high-Z axis Z-plate

  - We add an additional guide block.

  - This requires:

    - The spindle nut attachment to be moved down:

      - Distance = Length of guide block + spacing between blocks

    - The spindle needs to move down with the same Distance

      - This requires the screw holes to move.
