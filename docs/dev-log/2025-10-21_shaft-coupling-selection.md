# 2025-10-21 — Shaft coupling selection

<u><joppe.verboven@student.kuleuven.be>[Niels Bosmans](mailto:niels@thinkler.be)</u>

- Couplings

  - Misumi SJC-25C-RD-8X10 (Claw coupling, red, highest stiffness)

    - 300 Nm/rad

    - 1°, 0.05 mm

  - Misumi slit coupling CPLCN25-8-10

    - 380 Nm/rad

    - 2°, 0.15 mm

  - Misumi bellow type CPBSC25-8-10

    - 330 Nm/rad

    - 2°, 0.15 mm

  - Misumi servo / disc coupling CPDW25-8-10

    - 450 Nm/rad

    - 1.5°, 0.12 mm allowed offset

- Control box

  - Step, direction, limit switch and Estop signal to a large connector at the front of the Mekanika control box

  - Separate box with

    - Power supply

    - Motor drivers

    - Arduino Opta

    - DAQ system

    - Accelerometer connections

  - Only design when we have tested 1-DOF system with linear encoder

- Linear encoder

  - Look for sealed linear encoder, if not available, design own sealing
