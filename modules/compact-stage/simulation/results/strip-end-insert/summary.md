# strip-end-insert — results

Fit check of the strip end concept of Niels Bosmans, with corner pockets in carriage-top, stepped
scraper lips and a spring end, and the membrane model of the strip. Regenerated by:

```bash
python modules/compact-stage/simulation/cases/strip-end-insert/run.py
```

## The short answer

- **The carriage hits the insert because it passes over it.** The carriage comes from the stage
  middle, so every part of carriage-top and the scraper that ends up beyond the insert has
  passed over it. Carriage-top is only 0.35 mm above the strip, and the insert stands 0.75 mm
  above it.
- **A corner pocket in carriage-top solves that.** 1 mm deep and 12 mm long from the end face, it
  clears the insert up to the first damper touch. 19.5 mm long, it also clears it in a crash. It
  takes away about 25 mm³ of aluminium.
- **The scraper lips must step back behind the insert,** to 11.3 mm from the end face, as in the
  drawing. The scraper then grows into a deeper corner pocket. That works only beside the strip
  proper, over the ear: further in, the strip rises towards the carriage slope and would touch a
  lip there. So the insert moves from y = 13.2 to 8.5 mm and gets a little smaller (Ø6, M2 screw).
- **A spring end fits.** At one strip end the inserts sit on sliders, pushed by springs in a
  pocket milled from the top, 8.5 × 30 mm, 8.5 mm deep, with 4.25 mm of wall. The strip ear covers
  it. The spring sets the pull: 0.1 mm of travel then changes it by about 2.3 N instead of 50 to
  100 N.
- **Under the carriage the pull is even across the width.** Near the strip ends it runs along the
  edges, as before.

## Spring

Two springs at one strip end, one per insert, each 62.5 N (125 N for the strip):

| | Value |
| --- | ---: |
| Wire, mean diameter, active turns, free length | Ø1.2, Ø6.3, 6, 20 mm |
| Rate | 12.1 N/mm |
| Compression at 62.5 N | 5.2 mm |
| Shear stress at 62.5 N | about 750 MPa |
| Force left before the spring is solid | 63 N |
| Pull change per 0.1 mm of travel, with the springs | 2.3 N |
| Pull change per 0.1 mm of travel, without a spring | 50 to 100 N |

The wire values are typical values for stainless spring wire, not from a data sheet. The real
spring comes from a maker's catalogue.

## Membrane model

| Place | Carriage at the end of the travel: middle / highest | Carriage in the middle: middle / highest |
| --- | ---: | ---: |
| 15 mm from the strip end | 0.06 / 8.1 | 0.00 / 8.0 |
| 30 mm from the strip end | 0.24 / 5.3 | 0.00 / 6.3 |
| First bottom roller | 0.68 / 1.64 | 0.99 / 1.01 |
| Middle of the arch | 1.02 / 1.02 | 1.00 / 1.00 |

Beside the inserts the strip is squeezed sideways by up to 10 MPa. All values:
[`membrane.json`](membrane.json).
